# Packages

| Package                        | Directory              | Description                                                                         |
| ------------------------------ | ---------------------- | ----------------------------------------------------------------------------------- |
| [`schizomatic`](./schizomatic) | `packages/schizomatic` | The public package. It re-exports the runtime.                                      |
